Como a versão real funcionará

O GitHub fornece os registros públicos de Issues e PRs. Esta primeira integração distingue código em PR, pendência aberta e registro fechado. PR aberta ou Issue fechada não provam teste, aprovação nem integração. A classificação por abas é provisória e não prova execução por agentes.

A página consulta a API pública do GitHub ao abrir e verifica atualizações aproximadamente a cada 5 minutos enquanto estiver visível. A API impõe limites de requisições; em falhas, mostra o erro sem inventar andamento. Até 100 registros recentes por repositório e estado são carregados (sem paginação). Não há login, alertas, capturas antes/depois, controle de agentes ou autorização de ações nesta versão.
